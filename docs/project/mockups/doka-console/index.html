À regarder

  • Le logo. Le logo horizontal du kit Signal, à sa largeur minimale de 220 px, dans le menu ; le D seul quand la place manque (menu réduit, téléphone). Le nom n’est plus tapé à côté du symbole.
  • Le thème. Papier, charbon et jaune du kit, tels quels ; le thème sombre est sur le charbon du kit. Le jaune marque l’action principale, avec du charbon dessus. Le bouton ci-dessus montre l’autre lecture : action principale en charbon.
  • La navigation. Un menu latéral identique dans les deux entrées, réductible. Sur téléphone : un tiroir, et pour l’atelier une barre du bas avec « créer » au centre. Les crédits sont toujours en haut à droite.
  • Le chat. Comme les chats d’IA courants : une question d’accueil, une seule zone de saisie avec ses outils dedans, l’envoi en bas à droite, des suggestions, la réponse sans bulle, l’affiche dans un panneau à côté.
  • Réduisez la fenêtre sous 900 px, ou utilisez le mode téléphone du navigateur, pour voir la version mobile.
