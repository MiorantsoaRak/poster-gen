        Ma première affiche

        1. Présentez le produit

          Joignez une photo dans « Message », puis indiquez le nom, la variante et le prix exact en ariary. Vous pouvez aussi utiliser « Pas à pas ».

          Si vous êtes bloqué

          Dans une nouvelle affiche, distinguez la photo du produit d’une image donnée pour son style.

        2. Relisez l’offre et le coût

          Vérifiez la photo, les textes et le style avant de générer. Choisissez « Publication » pour publier directement sur votre Page.

          Si vous êtes bloqué

          Si le prix est dessiné dans l’image, le changer demande une nouvelle version. Vérifiez le coût avant de continuer.

        3. Comparez la version à l’original

          Vérifiez la forme, la couleur, le prix et chaque mot. Refusez la version si un détail est faux.

          Si vous êtes bloqué

          Un produit intégré à la scène reste dans cette image. Signalez les détails qui diffèrent de la photo.

        4. Confirmez le fichier final

          Examinez l’image à pleine taille avant de confirmer le PNG exact qui sera utilisé.

          Si vous êtes bloqué

          Une version approuvée peut encore avoir un fichier à confirmer. Ouvrez cette affiche depuis « Affiches à préparer ».

        5. Choisissez la destination

          Téléchargez le PNG, ouvrez le partage du téléphone ou préparez une publication Facebook. Pour plusieurs affiches, vérifiez leur ordre et le nom de la Page avant l’envoi.

          Si vous êtes bloqué

          Pour reconnecter la Page, ouvrez « Mon compte ». Si le résultat d’un envoi est inconnu, vérifiez votre Page avant de répondre.
