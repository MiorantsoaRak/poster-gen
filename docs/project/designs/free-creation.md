### Shipped wire contract


- `POST /api/free-creations` takes `words`, ordered `photos` (original asset hashes), optional `reference` (a style asset hash) and `default_style`. `POST /api/free-creations/{id}/turns` takes `words` with `If-Match`. Both return 202 with `creation_id`, `job_id` and `status_url`.
- `GET /api/free-creations/{id}` returns the revision, creation status, original attachments, document, ordered turns and current confirmation. A turn is its job as `GET /api/jobs/{id}` tells it: `status`, `error_code`, `credit` (`pending`, `spent`, `given_back`), with `words`; a completed turn also names its immutable render and PNG hash. A correction sends the previous image and the original photos, not the reference again: the previous image carries its layout. `GET /api/renders/{id}/preview` serves that file. A free document has `kind=free`, a display title taken from the first request, and a null price. Its input row groups the original attachments. Its JSON schema uses the existing immutable version table. No SQL migration is needed.
- The shared confirmation endpoint checks the current render ID, revision, PNG digest and four review points. It returns the ordinary confirmation download URL. Facebook picks the current feed confirmation using the same query as for a guided poster.
