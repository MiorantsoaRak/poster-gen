# Editor review against web interface practice — 2026-11-13

**Scope:** the editor after T-EDITOR-STEPS (R-POSTER-EDITOR-004, 005, 006; D-POSTER-EDITOR-004): `frontend/src/App.vue`, `frontend/src/style.css`, and the refusal table in `backend/src/affiche/api.py` (read only).
**Reviewer:** the agent that built the task, so this is not an independent review. A fresh reviewer must still read the result.
**Method:** (1) a script listed every control with a `disabled` condition and every `<details>`; each one was checked for a visible reason and for a needed input out of view. (2) Every refusal code of the server was read against what the editor does with it. (3) A checklist pass: focus, keyboard, labels, target sizes, forms, error placement, loading and empty states, phone, reduced motion, contrast, language attributes. No skill checklist was loaded; the list is the reviewer's own.
**Verified by:** build, 26 Vitest tests, the browser smoke (bundled Chromium, desktop pointer, stub providers). **Not verified:** a real phone or any touch pointer, Safari or Firefox, a screen reader, the paid providers.

Severity: **high** = the owner is blocked or misled; **medium** = the owner loses time or must guess; **low** = polish.

## 4. Visual language (R-POSTER-EDITOR-006): what was applied, and one deviation

- Glass on: the header, the fixed action bar of one-column screens, the paid-confirmation dialog (and a light blur of the page behind it), the poster sheet of the phone steps, notices and errors. Solid fallback first, `@supports`, off under reduced transparency or reduced motion through two tokens.
- **Deviation:** the three large panels (fidelity review, final file, a style) stay solid, although the requirement says "dialogs and sheets". Colours are judged in the first two, and a first build showed the page's poster tinting the panel around the comparison (kept out; no screenshot of it remains). On a phone they fill the screen, so glass would show nothing. To be confirmed by the user.
- The stage is a well darker than the panels and the poster carries the only shadow. The main action left the title row for the head of the stage, beside "À faire": the stage is sticky, so the poster and its action stay in view while a long tab scrolls.
- The progress line of the title row now reads « Préparation, Génération, Fidélité, Téléchargement »; on a phone the short form names the phase instead of "Étape 4 sur 4", which would contradict the step indicator.

## 5. Decisions for the user

1. **Accent colour against style (F7).** Today a style imposes its colour and says so. Alternative: a colour chosen by hand wins until the owner picks another. Which one?
2. **Glass on the large panels (section 4).** Keep them solid, or accept the tint?
3. **« Retour » on the first editor step (H6)** and **« Réglages » before the first version (H5).** Both follow the requirement as written; say if the owner's session shows a need.
4. **F11, F12, F14** need backend or design work: put them in TODO if they are wanted before the pilot grows.

## 6. Smoke assertions

All 188 assertion lines of the previous smoke are still present, word for word; none was deleted. 83 lines were added (271 in total). Lines that are not assertions and were removed or replaced: three clicks that opened a closed section (« Ce que l’IA dessine dans l’image », « Ajuster ce texte avec une consigne »: both are open sections now, and the smoke asserts they are visible), and two clicks on « Réglages avancés », now the « Réglages » tab.
