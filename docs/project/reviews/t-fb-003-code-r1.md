# Code review r1 — T-FB-003: publishing a confirmed poster on the shop's Facebook Page

Reviewer: Codex, read-only, 2026-11-21. Verdict: REJECT (two P1, four P2, all concrete; the ten choices made beyond the design ruled sound). Answered in the code the same day; see r2.

**P1 — Two sheets can both publish after the server clock moves backward.** Both sheets saw publication A. The first sends B, but B’s `sent_at` sorts before A. Once B settles, the second sheet still passes `seen == A` and sends again. Use database insertion order for both the admission check and the list, and keep `sent_at` for display. Test with a clock that steps backward between A and B. [facebook_publish.py:154](backend/src/affiche/posters/facebook_publish.py#L154) · [list ordering](backend/src/affiche/posters/facebook_publish.py#L85)

**P1 — Shutdown can release the process lock while a publication handler is still alive.** When a request is cancelled, its shielded task continues in `_RUNNING`. Shutdown closes the service and releases the lock without waiting for that task. A replacement server can therefore mark its row `unknown` while the old handler can still send. That invalidates the premise that makes the owner’s « Elle n’y est pas » safe at restart. Drain admitted publication tasks before disposing the engine and releasing the lock. [facebook_publish.py:226](backend/src/affiche/posters/facebook_publish.py#L226) · [api.py:584](backend/src/affiche/api.py#L584)

**P2 — A stale confirmation leaves the owner retrying the same obsolete file.** Save the poster in another tab, then submit the open sheet. The server returns `facebook_stale`. The sheet reloads only the Page and publications, so the next tap sends the same rejected `confirmation_id`. On this refusal, also reload the poster revision. If it changed, close the sheet and use the existing flow to verify the current poster. [App.vue:1866](frontend/src/App.vue#L1866)

**P2 — A definite file error is reported as a lost answer.** A damaged PNG returns `503 export_missing` before admission. The panel discards that error and directs the owner to a publication line that was never created. Preserve the server’s `export_missing` message. For a genuinely lost answer, point to a line only when the refresh finds one attributable to the attempt. [App.vue:1858](frontend/src/App.vue#L1858) · [facebook_publish.py:225](backend/src/affiche/posters/facebook_publish.py#L225)

**P2 — Saving a new revision hides the poster’s publication history and owner controls.** An `unknown` publication belongs to the poster and Page. Once the confirmed preview becomes an earlier version, `captionShown` becomes false and the watcher clears the list. The owner must confirm another revision to answer a question about the previous post. Load history for the open poster and apply the current-confirmation condition only to the new-send button. [App.vue:1816](frontend/src/App.vue#L1816) · [App.vue:1835](frontend/src/App.vue#L1835)

**P2 — The owner can publish before seeing the image.** If the sheet preview is slow or fails to load, « Publier » remains enabled. Track the sheet image’s load and error state, enable submission after it loads, and offer a retry on failure. [App.vue:2598](frontend/src/App.vue#L2598) · [App.vue:2603](frontend/src/App.vue#L2603)

**Choices.** All ten listed choices are sound, including the 422/409 split, poster-bound hash and surrogate rejection, decimal size limit, settlement retries, `unknown` on a send exception, and `said_by_owner=false` for absence. The outcome mutation, Page summary on the list, stub markers, and three panel choices also fit the design. For simplification, the list and outcome routes can drop their unused `make_graph(settings)` calls because provider-off already excludes both routes.

**Test gaps.** Of the design’s named publish checks, the admission-refusal coverage lacks an explicitly **suspended shop**. The ended-session test deletes the session and never exercises suspension with the session row intact. The file test damages the PNG but never removes it. The four named `after-restore` checks are also absent and assigned to T-FB-004. Beyond the design list, add the backward-clock and shutdown-with-a-detached-send regressions above. This was a read-only review. No suite or smoke result is counted.
