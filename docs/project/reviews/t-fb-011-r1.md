# Review r1 — T-FB-011: what the shops read about publishing posts, and the runbook's lines

Reviewer: Codex, read-only, 2026-11-22. Verdict: APPROVE WITH FIXES (five sentences made true to the code: what Facebook keeps of an unfinished post, the limit lowered during a sending, the photos' ids and the owner's answer, the draft's identifiers, what « Publier sur ma Page » does). All five applied; not reviewed again.

1. **« Une image envoyée pour une publication qui n’aboutit pas reste chez Facebook, sans être montrée sur votre Page. »** (`terms.py:35`, `donnees.html:67`, `deploy/README.md:611`). Facebook can publish an image on its own even though the requested post fails. A stop can also occur before some images are uploaded. Use « Une photo reçue par Facebook et restée sans publication y reste, invisible sur votre Page. L’atelier ne la supprime pas. Si Facebook publie une photo seule, vérifiez votre Page. » Apply the same qualification to the runbook and remove “Nothing to do.” (`facebook.py:193`, `facebook_posts.py:499`, `api.py:205`)

2. **“A post already being sent when the limit is lowered stops before it is published.”** (`deploy/README.md:601`). Lowering the limit stops a post only if it exceeds the new limit and the change precedes the final check. Use “If the post exceeds the new limit, it stops at the next check. Once its status is `posting`, a limit change cannot stop it.” (`facebook_posts.py:408`, `:448`, `:523`)

3. **« Ce qu’il a retenu de la réponse de Facebook (…) »** (`terms.py:33`, `donnees.html:46`). Both lists omit the Facebook photo IDs saved on the server after successful uploads, even if the post later fails. The terms also omit the post ID and the owner’s answer. Use « Le service garde aussi les identifiants des photos que Facebook lui renvoie. Selon le résultat, il garde l’identifiant et le lien de la publication, ou un code d’erreur. » In the terms, add « Si vous indiquez que la publication est sur votre Page ou qu’elle en est absente, le service garde votre réponse. » (`facebook_posts.py:434`, `:459`, `:625`)

4. **« Votre publication en préparation (les affiches choisies, leur ordre et sa description) »** (`donnees.html:54`). The saved draft also contains a request ID and, when known, the ID of the post being followed. Add « Le brouillon garde aussi un identifiant de demande et, s’il est connu, celui de la publication à suivre. » (`publish.ts:31`, `ShopPublish.vue:169`)

5. **« “Publier sur Facebook” et “Publier sur ma Page” : Facebook reçoit (…) »** (`donnees.html:67`, `deploy/README.md:546`). The final-panel button opens the publishing page for one poster. Confirmation sends the request. Facebook receives the photo IDs in order in the final call, with a description only if supplied. Use « “Publier sur ma Page” ouvre la page de publication pour cette affiche. Après votre confirmation, le service envoie les images à Facebook, puis leurs identifiants dans l’ordre choisi, avec votre description si vous en avez saisi une. » In the runbook, replace the parenthesis with “The final panel opens this page for one poster.” (`App.vue:1826`, `ShopPublish.vue:328`, `facebook.py:335`)

**APPROVE WITH FIXES**
