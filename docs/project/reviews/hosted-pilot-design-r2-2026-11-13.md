# Hosted pilot — design review round 2, phase B on the box (2026-11-13)

Subject: designs/hosted-pilot.md v3, "Phase B — the box `mx1`". What changed since round 1: phase B was an outline for a free machine with its own Caddy and systemd; it became one container on the shared box, in PPN Market's pattern. One fresh subagent, read-only, nothing run. Verdict: **APPROVE WITH FIXES**. Claude's decision on each point is in the last column; the fixes are design v3.1 and ADR-069, not reviewed again.

| # | Sev. | Finding | Decision |
|---|---|---|---|
| 1 | P1 | A new named volume takes its owner from the image folder; uid 10001 could not create the database or the lock in `/data`. The host backups folder must belong to that user too | `install -d -o 10001 -g 10001 /data /backups` in the Dockerfile; `install -d -m 700 -o 10001 -g 10001` in `deploy.py` |
| 2 | P1 | "Back up with the new image" fails on the first deploy (no database), and a backup failure leaves the old container stopped | Skipped when `/data/affiche.db` is absent; on failure the old container is started again and the release exits 1; `daily.sh` runs after the start |
| 3 | P1 | The non-secret environment was not specified: `IMAGE_PROVIDER` defaults to `stub` and is recorded for good at the first start; `DATA_DIR` defaults to a read-only folder; the default trust list puts every phone behind Caddy's address | Written in `deploy/compose.yml`; checked in the new image before anything stops; the settings refuse a host off loopback with the default trust list |
| 4 | P1 | Narrow only the session test of the access boundary; an early return for other paths would turn every missing static file into a 500; mount after the routes; `no-store` under `/api/` only | Done as described, with a test (page, hashed file, missing file, `/api/*` closed, Origin check on `/`) |
| 5 | P1 | Parallel wrong passwords pass the count together; forty Argon2 checks at once would pass 1 GB and restart the container in the middle of a paid job | At most two verifications at a time (`auth.VERIFYING`), with a test |
| 6 | P2 | `shm_size` does nothing with Playwright 1.64 (`--disable-dev-shm-usage`; shared memory and profile go to `/tmp`, inside the limit); two jobs can run at once, so two browsers | `shm_size` dropped; one browser at a time (a semaphore per event loop in `rendering.py`). A real 4096 px poster in the container is still to be measured |
| 7 | P2 | Dockerfile layer order; `--only-shell`; `CMD python`, never `uv run`; `init: true` | Done |
| 8 | P2 | Build memory unmeasured on a box without swap | Measured locally: the frontend build peaks at 479 MB; `NODE_OPTIONS=--max-old-space-size=512`; the runbook says to watch `free -m` during the first build |
| 9 | P2 | json-file logs die with the container at each release (R-005: 14 days) | `journald` driver with a tag; the box's journal retention is a runbook check, because it is shared |
| 10 | P2 | R-005 "a commit on origin/main" was not checked | `git fetch` and `merge-base --is-ancestor` in `deploy.py` |
| 11 | P2 | Caddy block from memory: two `handle` blocks, explicit content type, HSTS dropped, the down page cannot be tested by `verify.sh` | Block rewritten that way with HSTS; the box runs Caddy 2.11.4 (read on the box); `caddy validate` and a stop-and-fetch are steps of the first rollout. Still not validated |
| 12 | P3 | `STATIC_DIR` duplicates `rendering.BUILD_DIR`; `SPEND_CAP_SINCE` must be the UTC date; never mount `/data` read-only; `rendering.py` hid the browser error; stale design lines; rembg could be left out | Boolean `SERVE_FRONTEND`; UTC date in `deploy.py`; runbook line; the error's type is logged; lines corrected; rembg kept (no lock-file change for a path the pilot does not use) |

Checked and found correct by the reviewer: Chromium runs without its sandbox by Playwright's default, so the dropped capabilities and the unprivileged user are fine; the application writes only under `DATA_DIR` and `/tmp`; `uv sync` installs the project in place, so `BACKEND_DIR` resolves to `/app/backend`; fonts are tracked and reach the image through the git archive; uvicorn 0.54 accepts comma-separated networks and takes the right-most untrusted address (hence "no AAAA"); every route is under `/api/`; the process lock is released on exit and the backup takes none; the provider timeout (180 s) fits the 5-minute stop; single-quoted secrets keep their `$` signs.
