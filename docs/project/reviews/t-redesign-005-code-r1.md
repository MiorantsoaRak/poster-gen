**APPROVE WITH FIXES.** I found regressions in drawer focus and the 360 px layout. I found no change to money requests, their confirmations, password storage, or the authentication epoch that discards late answers. Routes are intact, including `#/money`, and Overview is absent.

### Medium severity

1. **Back and Forward can leave the destination behind an open drawer.** Sidebar clicks clear `drawer`, but `navigate()` also runs on browser history changes. With the drawer open, Back changes the route and tries to focus an `h1` whose `main` is still inert. Clear `drawer` at the start of `navigate()`, before the existing `nextTick` focus. Add a smoke step that opens the drawer, goes Back, and checks the previous heading has focus and the scrim is gone. [Admin.vue:291](frontend/src/admin/Admin.vue#L291)

2. **Closing the drawer leaves its links reachable during the exit animation.** The background becomes interactive immediately, but `visibility: hidden` is delayed 280 ms. After Escape returns focus to the menu button, an immediate Shift+Tab can enter the departing sidebar. Bind `inert` to the sidebar whenever it is in drawer mode and closed. Keep the animation. Test immediate reverse Tab before waiting for the sidebar to become hidden. This also lets the media-query change handler own the reactive width state. [admin.css:134](frontend/src/admin/admin.css#L134) · [Admin.vue:525](frontend/src/admin/Admin.vue#L525)

3. **The 360 px shop card regresses from one column to two.** Available and En attente share a row, as do Posters and Last poster. The existing smoke checks alignment and sideways overflow, both of which pass with two columns. Use a single grid track or restore block flow. Check that each successive cell starts below its predecessor at 360 px. The DOM order and visually hidden table headers can stay. [admin.css:196](frontend/src/admin/admin.css#L196) · [admin_browser.py:392](frontend/tests/admin_browser.py#L392)

4. **The new filter is a 14 px field on phones.** Its accessible label is correct and its target is 44 px high, but the input inherits `font` from the wrapping 14 px `label`. D-ADMIN-005 requires fields of at least 16 px at 360 px. Set `.filter input { font-size: 16px }` and assert the computed size alongside the target check. [admin.css:60](frontend/src/admin/admin.css#L60) · [admin.css:95](frontend/src/admin/admin.css#L95)

5. **Fractional viewport widths can expose both menus.** Between 1180 and 1181 CSS px, neither media query applies. The base fixed sidebar is visible without drawer positioning, both toggles appear, and JS considers the viewport narrow. Zoom can produce fractional CSS widths. Use complementary conditions in CSS and `matchMedia`, such as `(width > 1180px)` and `(width <= 1180px)`. On widening, if the focused drawer Close button disappears, move focus to the rail toggle. The resize smoke currently checks the scrim and `inert` only. [admin.css:96](frontend/src/admin/admin.css#L96) · [admin.css:130](frontend/src/admin/admin.css#L130) · [Admin.vue:112](frontend/src/admin/Admin.vue#L112) · [admin_browser.py:1521](frontend/tests/admin_browser.py#L1521)
