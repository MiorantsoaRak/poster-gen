# Code review r1 — T-FB-014: drag to reorder the draft's posters

Reviewer: Codex, read-only, 2026-11-22. Verdict: REJECT (three P1, one P2: a drop behind an open sheet, a drag left running when its handle is removed, an unannounced keyboard move, the grid's numbers during a drag). The P3 (no grip on a lone poster) is answered by the design's text: a handle when the draft holds two posters or more. See r2.

- **P1 — A drop can change the draft behind an open confirmation sheet.** Hold a mouse drag across one row, then use Tab and Enter to open « Publier… » before releasing the mouse. The sheet captures the original order. Releasing the mouse commits the new order, so confirming sends a different order from the one now stored. Call `settle()` when opening the sheet, before capturing its items. [ShopPublish.vue:274](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/frontend/src/ShopPublish.vue:274)
- **P1 — Removing the captured handle can leave the drag running.** Start dragging one of two posters while a candidate refresh is pending. If the refresh removes either poster, Vue removes both grips. Capture loss on a detached element is delivered to `document`, so the handle’s listener misses it. The animation frame and Escape listener survive, and `grab` blocks the next drag. Handle `lostpointercapture` on `document` while a grab is active, filter by the grabbed pointer ID, and remove that listener in `settle()`. Apply the same ID check to `pointercancel` so a second finger cannot cancel the first finger’s drag. [ShopPublish.vue:523](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/frontend/src/ShopPublish.vue:523)
- **P1 — A repeated keyboard move can go unannounced.** Move a poster to second place with ArrowDown, return it with « Plus tôt », then press ArrowDown on its grip again. The status text still says “place 2”, so Vue makes no live-region update for the second arrow move. Call `said(id)` after a successful button move as well. [ShopPublish.vue:443](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/frontend/src/ShopPublish.vue:443)
- **P2 — The two sets of order numbers disagree during a drag.** Cross a row and hold the pointer. The chosen list previews the new positions, while the confirmed-poster tiles still display the stored positions. Use `placeOf(item.id) + 1` for the tile badge too. [ShopPublish.vue:569](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/frontend/src/ShopPublish.vue:569)
- **P3 — A single chosen poster has no grip.** The design specifies a handle per chosen poster. Render it for the one-row case and let movement at either boundary do nothing. Make its `aria-describedby` conditional if the help text stays hidden. [ShopPublish.vue:522](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/frontend/src/ShopPublish.vue:522)

All five listed design choices are sound, including the stale-draft guard and pointer-drop announcement. This was a read-only source review. Tests and real-phone behavior were not independently verified.

**REJECT**
