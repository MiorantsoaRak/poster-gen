**APPROVE WITH FIXES** — The approach fits the intended scope, but resolve these design gaps before implementation.

1. **P1 — Persist which brand-compilation behavior a scene used.** [Design line 7](docs/project/designs/editor-refinements.md:7) preserves the recorded headline while distinguishing new scenes from historical refinements, but defines no discriminator. [`request_refinement`](backend/src/affiche/posters/visuals.py:268) rebuilds instructions from that stored headline. Simply exempting refinements from deduplication would reintroduce the separate brand heading when refining a newly deduplicated scene. Specify a server-owned marker in existing job JSON, absent for legacy scenes and inherited through refinements. Test both legacy and newly deduplicated refinement chains without changing old payload hashes.

2. **P1 — Account for scene cropping in the logo-region guard.** [Design line 19](docs/project/designs/editor-refinements.md:19) compares canvas placement with a stored reservation, but existing zoom/pan changes where that reservation appears beneath the overlay ([App.vue](frontend/src/App.vue:1160)). An unchanged logo box could pass while covering generated content after cropping. Define crop-aware validation, or the smaller solution: require the original framing while a corner logo is included. Apply the rule on the server and client; test zoom/pan and restoration in all formats.

3. **P1 — Specify the complete seal-copy and historical-selection transitions.** [Design lines 15–19](docs/project/designs/editor-refinements.md:15) require a copy, but [`copy_creation`](backend/src/affiche/posters/store.py:298) normally retains its selected scene. Define how the copy clears that scene, restores hidden text layers and removes the circle shape before corner placement. Also define returning to a legacy seal: [`chooseVisual`](frontend/src/App.vue:1143) currently restores the disc only if the current logo already has `shape: circle`. Corner metadata alone cannot restore this. Test seal → copy → corner and historical selection, preserving the original document and confirmed PNG. Explicitly apply disc coverage validation before refinement enqueue too: the current disc guard exists in export, not refinement admission.

4. **P2 — Use one normalization algorithm across Python and TypeScript.** [Design line 7](docs/project/designs/editor-refinements.md:7) leaves “case-fold/lowercase” interchangeable. They differ—for example, Python casefold matches `Straße` with `STRASSE`, while JavaScript lowercase does not. Choose identical normalization semantics and shared test vectors, including punctuation, accents, multiword boundaries and characters whose case mappings differ.

5. **P2 — Protect manual palette choices from outstanding sampling.** [Design line 9](docs/project/designs/editor-refinements.md:9) discards results when the product changes, but an earlier sample can still overwrite a manual override or newer retry for the same poster. Invalidate outstanding sampling when a manual choice or new sampling request starts. Test delayed sampling followed by an override, reload and generation; the displayed and submitted palette must remain the accepted choice.

The remaining foundations are sound: omitting absent `logo_corner` can preserve canonical contexts; existing document validation binds the logo layer to the snapshot asset, and export loads that uploaded file. Confirmed downloads read their immutable PNG directly. Add explicit byte-for-byte legacy canonical/hash fixtures. The reservation wording, sticky-control approach, local sampling, and prohibition on unauthorized paid generation or release are appropriate.
