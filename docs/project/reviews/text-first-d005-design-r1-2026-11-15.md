**Verdict: REJECT.** The field-based approach is sound, but compatibility and paid-request behavior need fixes before approval.

1. **P1 — Legacy replay is not fully preserved.** [Design:254](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/docs/project/designs/text-first-generation.md:254) adds optional `words`, but reads hash the parsed model—including defaults—before replay ([reads.py:275](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/backend/src/affiche/posters/reads.py:275)). Adding `words: null` changes old hashes unless explicitly excluded. Also, converting cards only in `readThread` misses old stored answers arriving through `ask` ([ChatView.vue:218](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/frontend/src/ChatView.vue:218)). Preserve absent-field hashes, normalize cards at both entry points, and retain replay compatibility beyond one release. This blocks R-004’s legacy-card criterion.

2. **P1 — The triggering brand request can still produce `same`.** [Design:261](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/docs/project/designs/text-first-generation.md:261) leaves a brand already inside the title unchanged. Existing versions can store `brand: "Sony"` and `title: "Sony WH-CH720N"` even though compilation omits the separate brand ([visuals.py:251](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/backend/src/affiche/posters/visuals.py:251), [plans.py:354](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/backend/src/affiche/posters/plans.py:354)). A valid answer `{brand: "Sony", title: null}` then changes nothing. Apply separation when the brand field is explicitly returned, before dropping equal values. Test this existing-brand case.

3. **P1 — Word membership does not prevent invented specifications.** [Design:260](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/docs/project/designs/text-first-generation.md:260) allows recombining words freely. From `RAM 8 Go / stockage 128 Go`, the model can return `RAM 128 Go`; every token passes [name_words](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/backend/src/affiche/posters/plans.py:16) and the headline screen. This violates R-005’s no-invented-specifications criterion. Preserve complete specification spans, including numbers, units and punctuation; token membership alone cannot support the stated guarantee.

4. **P1 — The quoted consequence can differ from the submitted request.** The cost uses the selected version, but `revise` uses mutable editor settings ([design:267](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/docs/project/designs/text-first-generation.md:267)). Disable “Textes dans l’image” in steps, return, then request a brand change: the card charges for a redraw, while [headlineBody](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/frontend/src/App.vue:303) omits that brand entirely. Define how the version’s settings and current settings produce the exact advertised request before payment.

5. **P2 — “Restore old texts” may restore words the image never showed.** [Design:282](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/docs/project/designs/text-first-generation.md:282) captures values before editing. Those may already differ from the image after an edit in steps. The existing price flow deliberately captures the drawn amount ([ChatView.vue:257](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/frontend/src/ChatView.vue:257)). Specify rollback values from the selected version for drawn fields; otherwise restoration can leave export blocked and regress ADR-098.

6. **P2 — Free titles get the wrong validation.** [Design:236](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/docs/project/designs/text-first-generation.md:236) always limits titles to 60 characters without quotes or line breaks. A layer title permits 240 characters ([models.py:43](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/backend/src/affiche/posters/models.py:43)). Use `Offer` validation for free layer edits and drawn-title validation when generating. This misses R-005’s “editor’s own rule” criterion.

7. **P2 — Changing the displayed older version remains unspecified.** The list changes `looked`, while refinement uses `currentVisual` ([ChatView.vue:465](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/frontend/src/ChatView.vue:465), [App.vue:1110](/home/miorantsoa/Documents/Miorantsoa/Vite/affiche-ia/frontend/src/App.vue:1110)). The proposed adapter does not bridge them. Define and persist the target version before reading and applying a change; test an unchecked older version. Otherwise R-004’s “any version” criterion is unmet.
