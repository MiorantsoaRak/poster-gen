# Unified creation

Approved for design and implementation under the owner's 2026-11-26 instruction: “go for design then implementation”, choose relevant answers without asking; paid tests authorized. This formalizes the accepted research, not a request for another approval. R-FREE-07 remains binding.

| ID | Requirement and acceptance criteria | Status |
| --- | --- | --- |
| R-UNIFIED-01 | New creation opens Libre; no Message generation choice remains. Pas à pas is optional preparation for the same free image workflow. Existing guided posters and downloads remain accessible. Old Message entry links lead to the appropriate new creation or legacy editor without losing saved work. | Approved |
| R-UNIFIED-02 | Short/detailed prompts with no photos, product photos, reference only, or photos plus reference can generate. Explicit words override references; layout matching and style inspiration are distinct choices. Quality defaults do not impose a single studio look or invent business facts. | Approved |
| R-UNIFIED-03 | User can include saved shop identity and lines, preview what is included, and use a supplied logo separately from the three photo slots. No supplied logo means no invented shop symbol, including when a reference contains one. All poster identity is model-rendered; original facts remain editable in the kit. | Approved |
| R-UNIFIED-04 | Attachments can be changed for a correction; previous versions retain their own source context. User can deliberately correct an earlier version; the selected base is explicit. Failure preserves the previous successful image and its confirmation. Replay does not charge twice. | Approved |
| R-UNIFIED-05 | Pas à pas prepares exact content and visual direction with optional photos/reference/kit. No manual identity/font/layer controls for new posters. Seller reviews the assembled request before the shared paid confirmation. | Approved |
| R-UNIFIED-06 | Review prioritizes image, latest instruction and original sources; history is clearly historical, never presented as simultaneously current conflicting facts. Existing confirmation/download/publication invariants and ownership checks remain. | Approved |
| R-UNIFIED-07 | Mobile/desktop controls remain usable, with examples, recoverable failures, visible cost, preserved input on mode change and sensible scroll. Motion uses short transform/opacity transitions and respects reduced motion. | Approved |
| R-UNIFIED-08 | Each implementation slice receives a browser check; final build/unit/backend regression suites and scenario browser checks pass. Paid scenario matrix records inputs, settings, cost, artifacts and visual acceptance (facts, identity, products, layout, legibility); deficiencies trigger correction and retest. No claim of universal model accuracy. | Approved |

Out of scope: new image provider, training, public gallery, deployment, additional export formats, OCR certification, bulk generation. Keep existing immutable legacy data, not destructive conversion. No technical migration is implied by these requirements.
